Scrimba solo project - Movie Watchlist

Project breakdown -

- Implemented HTML structure for main application and movie detail pages.
- Created CSS styles for layout, theming, and responsive design.  First time attempting to use root variables as well - so much cleaner.
- Developed JavaScript functionality for searching movies and managing a watchlist from the OMDB API.
- Integrated local storage for saving and retrieving the watchlist and a "Load More" button.
- Added theme toggle functionality to switch between light and dark modes (New skill unlocked!)
- Included error handling for API requests and user interactions.
- Footer with my Github link and the theme toggle button

Specific things done above and beyond the original Scrimba project spec -

- Rendered individual movie pages
- Footer
- Load More button
- Dark/light mode toggle
- Changed the method to render the content onto pages - was implemented in an unsafe way (innerHTML)

Took about a week and a half from beginning to end - tried to stick to minimum 1 hour per day + 3 hours on weekends.

Tack on another 3-4 hours for the final fully polished version - I wanted to understand all the little things that should be done for a project to be completed at a professional level.  Plus I learned a lot more useful JavaScript/CSS things besides.
